## 当前所在阶段

当前已推进到两套研发顶层及完整规划模块骨架，正在补齐功能和逐层衔接，尚未达到完整双 IP 功能原型。现有工作树 `rtl/` 包含 `upli/`、`tl/`、`dl/`、`phy/`；已建立 Endpoint/Switch 两套研发顶层和145个未实现接口壳；完整事务/逐跳协议功能及配套管理软件仍未完成。目录存在与否不单独证明功能，但当前验证也没有覆盖最终双 IP 全栈场景。

最近完成的是信用匹配优化的局部资格确认：九位宽 207 项语义 SAT、36 组发送单元、32 组实际双端、27 组所有权归纳、60 组物理测量和 12 个实际映射分区。它降低了发送组合的标准单元面积，没有补齐其余协议层，也没有关闭目标频率。详见 `tl_credit_slot_selection_review.md`。
