# License Management

Recommended license layers, subject to legal review:

- User-space software, compiler, simulator, and tools: Apache-2.0.
- Linux kernel driver: GPL-2.0-only or another kernel-compatible license.
- RTL: Solderpad-2.1 or CERN-OHL-W.
- General documentation: CC-BY-4.0.
- Kimi-K3 weights: separate Kimi-K3 License; OwerFlow does not relicense them.

Before the formal v0.1.0 release, add the selected full license texts and SPDX/REUSE configuration.
