# Requirement Traceability

`traceability.csv` is the source of truth mapping requirements to owner directories, verification methods,
and evidence states. Reference an existing requirement before implementation; create a requirement or ADR
first when no suitable ID exists.

`kdlink_traceability.csv` is the release-specific gate for KDLink. Its status records must be
updated only from retained evidence, not from design intent or an analytical estimate.
