# Code of Conduct

Overflow contributors are expected to keep technical collaboration respectful, specific, and evidence
based. Welcome questions made in good faith, criticize designs and results rather than people, respect
privacy and attribution, and do not use harassment, discrimination, threats, sexualized attention, or
publication of another person's private information.

These expectations apply in repository issues, pull requests, reviews, project communication, and public
events where someone represents the project. Maintainers may edit or remove content, pause a discussion,
reject a contribution, or restrict participation when behavior harms contributors or the project.

Report conduct concerns privately to repository maintainers through the repository owner's verified GitHub
profile. Do not place sensitive personal information in a public issue. Maintainers should disclose
conflicts of interest, limit access to the report, seek the affected person's preferences when practical,
and respond proportionately. This policy does not replace applicable law or GitHub's platform policies.
