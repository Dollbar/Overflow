# Switch egress scheduler candidate review

This isolated leaf merges the existing Request/Response × VC queue-head slots into one packet stream per physical egress. It preserves first-stall ownership, body bubbles, full data/token fields and downstream backpressure. Response preference is bounded by the configurable completed-packet quota; class-local VC round-robin advances only on actual last-word acceptance. The module has no reservation or release output.

The final candidate tests cover (PORTS,VCS,DATA_WIDTH,RSP_BURST_MAX) = (1,1,8,1), (2,2,33,2), (4,4,544,3), (1,4,33,15). Across 8,300 checked cycles they exercise 2,764 completed-packet service events, 7,298 stalled valid egress cycles, 1,661 owned bubbles, 16 resets with an owner, and every one of the 50 configured queue-head slots. These counts are scheduler service events in a local generated-source test, not an integrated capacity ledger. A fixed service-order schedule cross-checks the Python deque oracle; randomized packet producers supply complete words and preserve stalled fields. The oracle selects from these actual inputs without reading DUT internals. The test compares all public outputs before the DUT sampling edge; stimulus is applied at the falling edge.

Seven actual RTL mutations all compile and fail the self-check with run exit 1: unlimited Response priority (cycle 3), stuck response VC round-robin (2), failure to lock a stalled first beat (21), owner lost in a bubble (22), ready broadcast to unselected queues (1), payload bit corruption (1), and premature packet completion (27). These mutants demonstrate the stated checker sensitivities, not exhaustive fault coverage. Quota values 0 and 16 both fail elaboration with the explicit unsupported-parameter module marker.

The final source passes four Verilog-2001 compiles, four strict Verilator `-Wall` checks and four Yosys hierarchy/proc/flatten/opt/memory_map/check-assert/stat checks. The applicable RTL skill gate reports zero errors and 14 advisory warnings. The missing-module RED is retained under `red/`; it is an interface-absence failure, not a functional RTL counterexample. The first implementation already passed behavior but failed strict lint on an implicit localparam width conversion; the explicit slice fix and the original failure remain recorded. Earlier skill formatting findings are retained separately.

`results/final/` contains the final candidate evidence. The independently relocated production-layout runner passes the same matrix under `release_replay/build/verification/ip_tops/switch_egress_scheduler/portable_final/`; every vector and coverage tuple is checked for equality with the candidate run. Artifact SHA verification is recorded in `freeze.json`. The release manifest lists six exact installable files; copy only those, never this development tree or its generated results. RTL dependencies: none. Runtime test tools: Python 3, Icarus Verilog/vvp, Verilator and Yosys.

Fairness requires eventual downstream acceptance and the current owner eventually supplying a valid last beat. The quota bounds packet service opportunities, not cycles or bytes. A malformed or permanently stalled producer cannot be preempted or repaired here. Producers must preserve full fields when stalled. This leaf introduces no buffering and requires a reset epoch shared with its queues. Actual VC-queue integration, physical-top wiring, capacity-release closure, network deadlock/QoS proof, formal equivalence and PPA/STA are outside this candidate checkpoint. Per root instruction the integration test is deferred. Production RTL, inventory and top remain unchanged by this task.
