# Queued physical egress to typed 544-bit handoff

`switch_egress_typed_pipeline` composes one existing `switch_egress_pipeline` with one actual `switch_egress_repack`. The queue reserves complete packet units once and returns them exactly when its last word is accepted into repack storage. Repack owns one independent elastic word per physical egress. Its eventual downstream last-word retirement is a distinct event and never returns queue capacity again. Reset cancels both resource and typed-word epochs; cancellation is not retirement.

Helper parameters PORTS/VCS=1/2/4, TOKEN_WIDTH/UNIT_WIDTH and per-slot CAPACITIES retain pipeline meanings; DATA_WIDTH is fixed544. Header admission is a pulse accepting route-match, units, token, VC and Request/Response class atomically; body may begin only after that edge and must match saved token/owner. Slot=(response*VCS+vc)*PORTS+egress. All queue diagnostics/counters and scheduler selected/owned observations are retained. Outputs are the repack's full typed local_dl_header24, record_aux6, tl_msg2, tl_flit512, token, VC, response and last; `o_data` reconstructs exactly these 544 bits for the legacy local record consumer. Physical i_ready retires typed records; repack alone sends capacity-ready upstream. The aggregate error includes existing queue errors and repack's input VC diagnostic.

A candidate patch adds `BUFFERED_EGRESS_ENABLE=0` to `ualink_switch_top`. Default leaves its existing lookup/arbiter/fabric flow unchanged. Enabled mode supports DATA_WIDTH544 and PORTS1/2/4, and requires explicit `i_packet_header_valid`, `o_packet_header_ready`, `i_packet_units`, `i_packet_token`, `i_packet_body_token`, `i_packet_vc`, `i_packet_response`. Existing i_valid/data/last are body signals; i_dst is interpreted at header admission, using the top's existing unique route lookup. A body cannot infer or reserve its own header. Existing static/atomic route configuration selects the same lookup table. Header routing is saved by the queue owner and must not change with later i_dst noise. Quiescence includes no visible header/body, no source owner, no queue reservation and no repack-valid record. Default mode never interprets new header inputs.

This local 544-bit record is not a standard serialized UALink link frame. It preserves existing DLheader24/aux6/msg2/TLflit512 boundaries without decoding Control/Data/Auth source groups. No `tl_tx_prepared` integration or reconstruction is claimed. Standard TL/DL termination, re-encoding, hop semantics and packet-context generation remain external open boundaries. Additional required context is explicit; no guessed opcode or inferred class is used.

After installation run `python3 verification/ip_tops/run_switch_egress_typed_pipeline.py --label NEW --faults` and `python3 verification/ip_tops/run_switch_egress_typed_top.py --label NEW --faults`. Outputs are independent fresh-label directories under `build/verification/ip_tops/switch_egress_typed_pipeline/` and `switch_egress_typed_top/`; next review the typed boundary before any TL/DL attachment.
