# Single-resource egress packet queue candidate

Only a local packet-buffer microarchitecture, not UALink packing, VC partition, Req/Rsp reserved credits, or a complete Switch. Existing switch_egress_vc_queues and switch_egress_repack are shells; tl_tx_data_fifo is fixed two-bank 256-bit striping. This candidate reuses the actual upli_receive_fifo registered-read controller and gives it a synthesizable synchronous inferred memory. Physical KD28 mapping/STA is not claimed. Do not replace the inventory VC queue with this single-resource helper.

Parameters PORTS=1/2/4, DATA_WIDTH>0, TOKEN_WIDTH>0, UNIT_WIDTH=3..16, CAPACITIES packed per egress including zero. One unit is one complete DATA_WIDTH word supplied by the local caller, not inferred standard framing. Each egress has reserve_valid/units/token, write_valid/data/last/token, output ready/valid/data/last/token and release_valid/units. Additional public counters reserved/stored/completed and busy/errors support integration diagnostics. All use one clock and synchronous low reset.

reserve_ready depends only on previous state (no active writer, nonzero free capacity, no sticky error). Connect it to switch_credit_reservation.i_admit_ready; connect the actual egress grant pulse and whole grant_units to reserve_valid/units. A handshake creates exactly one packet descriptor and charges whole units locally once. Never send one reserve for every data beat. First write is on a later edge. Token is an opaque ordered descriptor label, preserved on every beat; repeated values across separate completed descriptors are allowed, so it is not a global uniqueness CAM.

One unfinished writer per egress. Bubbles are legal. Exactly N accepted writes, each with the saved token and last only at N, are required. A valid write without ownership, wrong token/last, inconsistent physical FIFO capacity, or a reservation exceeding old free capacity produces a per-egress sticky fail-stop from the following edge until common reset. On the diagnostic edge an already committed old head retains normal output qualification and may retire; its actual retirement is accounted. This avoids a reserve-error → output-valid → release → reservation-grant combinational loop. No new malformed write/reserve is accepted. Busy reserve backpressure is not error. A malformed last cannot make a partial packet visible. Other egresses remain independent.

No output is published until the final word actually enters storage. Backpressure retains the entire word/token/last. Completed packets retire in FIFO order. Only actual output last handshake emits one release of original N units; intermediate output beats and enqueue completion do not release reservation capacity. Queued first words may already be in the reused FIFO's internal read caches; this does not publish a partial packet. Concurrent release and reserve update by net units; old capacity eligibility remains conservative and matches the reservation module.

Reset must clear queue and reservation together and cancels all old tokens; RAM bits need not reset. Errors have no drop/rollback/recovery protocol beyond reset. This candidate is not installed into the current combinational fabric: that integration still requires holding ingress packet ownership after the first reservation, routing all remaining beats to its writer, and separate resource-domain partitioning.
