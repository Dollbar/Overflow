# Switch typed TL context candidate review

Frozen scope is an executable explicit adapter boundary. A real `tl_receive_context`/`tl_sequence` instance classifies each accepted record and advances only when the one-entry holding actually captures it. Full record544, token, VC, response and Last, both half classes, before-context and proposed demand/release metadata remain stable under backpressure. It neither generates prepared source groups nor transmits TL/DL packets.

The initial missing-module compile RED is `missing_red.log` (unknown module, exit2): interface absence, not a behavioral counterexample. The independent Python model is the pre-existing `model/tl` context/sequence/tenure implementation, snapshotted separately from RTL. New literal class sentinels, a separate elastic per-port oracle and full packed-output comparison check its connection and state commitment. Stimulus and expected protocol semantics still use that same existing Python context model to construct legal tenure programs; this is not independent specification certification. It does not use DUT internals to generate expected output.

No PPA, timing, full-protocol or equivalence claim.

Six actual RTL mutants compile and fail output checks: context commit while stalled(cycle8), swapped half classes(2), dropped before-metadata(9), Auth bypass(177), full-record bit543 loss(2), and overwrite-ready bypass(2). Failure logs and mutated source are retained. Portable replay runs with Python `-O`; critical validation does not rely on removable Python assertions. Portable fixture uses read-only links to existing TL/model dependencies; the runner snapshots individual source files before compilation and never needs build/development when installed at the release paths.

Installation: copy the six explicitly listed release files to their matching project paths; existing production files and inventory need no replacement. Run `python3 verification/ip_tops/run_switch_egress_tl_context.py --label NEW --faults`. Required unchanged RTL dependencies are tl_receive_context, tl_sequence, tl_control_tenure and tl_control_decode. Required independent Python dependencies are receive_context, credit_context, tl_sequence and tl_tenure in model/tl. freeze.json pins the bytes of these dependencies and the read-only integration sources used for contract review. Candidate generator scripts are historical development helpers, not release inputs.

This helper is not automatically safe after arbitrary local packet arbitration: independent incoming TL sequences need confirmed field association/reordering before sharing an outgoing sequence. Metadata is preserved, not a reconstructed complete Request/Response/Auth descriptor. It does not validate all command/address semantics, authenticate tags, map local Last to field boundaries, or allocate/return any capacity. `prepared_reconstruction`, `actual_tl_send` and `dl_attachment` remain false in evidence. Next work is a real field/Data/Auth assembler with the distinct capture/data-admission/wire-consumption contracts in the companion document.
