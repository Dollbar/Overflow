当前已私有接入三份用户提供的规范 PDF，共 426 页。公开来源登记在 sources.json（历史文档已清理）。正文阅读结论见 研读报告（历史文档已清理）。

2026-09-07：自动申请阶段网站只返回联系确认；此后用户手动提供了 Common 2.0、200G DL/PL 2.0、Manageability 1.0。详见 [接入状态](acquisition_status.md)。

三份申请通过 [官方目录](https://ualinkconsortium.org/specification/) 对应表单提交。Chiplet 与 128G 路径待范围确定后处理。文件可读不代表实施或发布所需的权利已全部解决。

接入时登记文件标题、修订版、勘误、SHA-256、来源、取得日期、可用主体及允许用途；不要在公开清单记录个人身份或授权凭证。未确认许可时不镜像规范内容，不将其随工程上传。

`private/` 仅目录所有者可访问，保存规范 PDF、SHA-256 清单、阅读抽取文件、表单输入、浏览器会话和提交回执；不入库。忽略规则只防误提交，不提供许可授权。需要额外隔离时使用负责人批准的外部资料目录，通过本地配置接入。

已建立 [验收要求台账](requirements.json)，共 110 条，当前 103 条正文确认、7 条阻塞；不是全部规范 SHALL 数量或通过测试数。模型阶段因 A19 重开 R101，原 104/6 是开工前快照。R001/R003/R004/R045/R101 新增有限的 模型证据（历史文档已清理），其余证据仍为空，全部 RTL 未实现。既有判据及 ID 保留，不把子模型通过升级为全条要求通过。R001–R004/R045 对应 station/bifurcation；R046–R077 见 [时钟专项](../docs/clock_and_rate_plan.md) 和 缺项审查（历史文档已清理），R078–R100 见 事务/恢复专项（历史文档已清理）。逐包开工门槛见 开工审计（历史文档已清理），当前进展见 模型自审（历史文档已清理）。工程参数、缓存及 STA 决策不混算为规范 SHALL。

[算术审查记录](arithmetic_review.json) 只记录 LLR 序号/窗口有限域诊断，不计作协议模型、RTL 仿真或形式证明。逐条追溯继续补充；只记允许保存的要求摘要和条款标识，不复制整份规范。
