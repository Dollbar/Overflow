# Open-Source Delivery Boundary

## Directly Redistributable

- Architecture and interface specifications, performance models, and traceability data.
- Model adapters, compiler, runtime, driver, and firmware source code.
- NPU and KDLink RTL, testbenches, formal properties, and build scripts.
- Behavioral memory, host, and link models.
- Reproducible reports whose inputs and generation commands are public.

## Excluded Artifacts

- Model weights, private datasets, and non-redistributable tokenizers.
- Credentials, license files, and private service configuration.
- Third-party binaries without a redistributable license and a reproducible acquisition record.

Every third-party dependency records its source, version, license, checksum, redistribution status,
acquisition method, and replacement strategy.
