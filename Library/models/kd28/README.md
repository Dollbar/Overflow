# KD28 Reusable Models

KD28 is the repository-owned name for portable infrastructure models intended to be replaced by selected
licensed technology collateral during physical implementation.

| Path | Scope |
| --- | --- |
| [`sram/`](sram/) | Single-port, simple-dual-port, and true-dual-port synchronous SRAM models |
| [`fifo/`](fifo/) | Parameterized synchronous and asynchronous FIFO wrappers built on the SDP model |

KD28 does not identify a foundry process or qualified 28 nm PDK. The models provide functional and mapping
contracts only at the evidence boundaries documented beside each package.
