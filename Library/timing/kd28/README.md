# KD28 Synthetic Timing Views

KD28 timing assets are repository-authored front-end assumptions for reusable infrastructure cells. They
do not identify or approximate a qualified foundry process closely enough for physical claims.

| Path | Scope |
| --- | --- |
| [`sram/`](sram/) | Synthetic fast, typical, and slow Liberty views for fixed KD28 SRAM cells |

Use these files to validate explicit black-box linking and STA constraint plumbing. Replace them with
licensed compiler Liberty before synthesis optimization, implementation, or signoff.
